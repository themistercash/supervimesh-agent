# Code de conduite

Nous voulons une communauté accueillante pour toutes et tous, quels que soient l'expérience, l'origine ou l'identité.

- Soyez respectueux et bienveillant, critiquez les idées et non les personnes.
- Pas de harcèlement, d'insultes ni de propos discriminatoires.

Les comportements inacceptables peuvent être signalés à contact@supervimesh.fr. Les responsables du projet
peuvent retirer des contributions ou exclure des participants qui ne respectent pas ce code.

Inspiré du [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
